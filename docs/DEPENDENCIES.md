## Достижимость находок

| Пакет | Где используется и оценка условий | Результат |
|---|---|---|
| vite | Локальный dev-сервер привязан к сети; обходы fs.deny и чтение файлов относятся к реальному инструментальному пути. На статическом `dist/` Vite-сервер не запускается. | Исправления в 7.3.6 |
| tar / supabase | Распаковка в старой установке CLI; untrusted tar не принимается пользовательским SPA. Critical относится к инструментариям установки, а не обработке турнирных данных. | CLI 2.116.0 больше не приводит tar в дерево зависимостей |
| ws | Старый Node-транспорт Supabase; браузер использует native WebSocket, SSR/Node-сервер приложения отсутствует. | После обновления ws отсутствует в дереве |
| postcss | Компиляция локальных CSS в Vite/Vue. Пользовательские CSS/sourceMappingURL и HTML-строки приложением не принимаются. | Транзитивно 8.5.28 |

Источники advisory: [Vite fs.deny](https://github.com/vitejs/vite/security/advisories/GHSA-v2wj-q39q-566r),
[node-tar decompression](https://github.com/isaacs/node-tar/security/advisories/GHSA-23hp-3jrh-7fpw),
[esbuild Windows server](https://github.com/advisories/GHSA-g7r4-m6w7-qqqr).
Оценка достижимости основана на импортах и путях исполнения этого проекта;
пересмотреть её при появлении SSR, загрузки архивов/CSS или esbuild-сервера.

CI выполняет `npm audit --audit-level=moderate`: оставшийся low не блокирует
сборку, новые moderate/high/critical блокируют. При очередном совместимом
обновлении Vite повторно проверить, исчез ли low без override.

Проверки после обновления: чистый `npm ci` без прежнего node_modules и `.env`,
сборка на Node 24.20.0, **172/172** тестов в каждом из трёх режимов SQL,
**59/59** браузерных проверок на новом Vite-процессе. Отдельно проверены
Supabase CLI и pg_dump/pg_restore. Предупреждения размера JS chunks остаются
для шага 11; обновление библиотек не объявляется оптимизацией размера.
