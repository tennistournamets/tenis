# Мобильная адаптация Bracketa

Начало: 8 сентября 2026. Основа: [повторный аудит](MOBILE-UX-AUDIT-2026-09-07.md).

Каждый этап завершается проверяемым набором изменений, обновлением этого плана и отдельным коммитом. Существующие исправления сохранности черновиков и серверные ограничения ролей сохраняются.

## 1. Рабочие действия и базовая адаптация — завершён 08.09.2026

Ветка `codex/mobile-foundation`.

- [x] M03: вкладки счётчика и доступные действия согласованы с серверными правами.
- [x] M04: футбольная сетка открывает голы/пенальти, live доступен только поддерживаемым видам.
- [x] M06, M12, M32: каждый шаг мастера виден сверху, фокус на заголовке, прогресс не скрыт, шапка помещается.
- [x] M10: корректные RU/LT адреса, предварительный вид ссылки, ошибка занятого адреса сохраняет форму.
- [x] M01, M13–M15: действия, регистрация, группы и длинный email помещаются на телефоне.
- [x] Проверки 320/390/430/768 px, RU/EN/LT, ролей и поддерживаемых форматов; build и сценарные регрессии.

Проверка первого этапа:

- 240/240 браузерных проверок: реальные компоненты в оболочке App, тестовые данные; 320/390/430/768 px, RU/EN/LT, роль × спорт × формат, поля и ошибки мастера.
- 29/29 существующих проверок форм и 59/59 общих UI-регрессий.
- 24/24 проверок логики и существующих серверных RPC, включая запрет итогового результата для counter и разрешённый live.
- Production build и `git diff --check` прошли. Проверки выполнены в Chromium touch-эмуляции; проверка физических телефонов остаётся этапом 4.
- На viewport 320 px измеренные страницы регистрации, групп, кабинета и аккаунта имеют scrollWidth 320 px. Длинные имена и статусы участников не перекрываются.
- Артефакты: `output/playwright/mobile-foundation/` (JSON, логи, скриншоты, исключены из Git). Повторяемый сценарий: `tests/manual/mobile-foundation.playwright.js`.
- Новых миграций и изменений серверных прав в этом этапе нет.

## 2. Мобильные матчи и работа организатора — завершён 08.09.2026

Ветка `codex/mobile-match-center`.

- [x] M02, M28, M31, M34: на телефоне первым открывается центр матчей с поиском по участникам, фильтрами статуса/этапа и читаемыми карточками; шапка турнира компактна, результат редактируется по одному матчу.
- [x] M25, M26: обычный вертикальный свайп прокручивает страницу, полноэкранная сетка сохраняет управление полотном, auto-fit пересчитывается при смене размера/ориентации.
- [x] M27: верхняя, нижняя сетка и гранд-финал double elimination разделены на самостоятельные мобильные вкладки с количеством матчей и локальными панелями управления.
- [x] M09: ручные пары и позиции сетки выбираются тапом, Enter/Space; drag остаётся дополнительным способом.
- [x] M24, M35, M37, M39: отклонённые заявки восстанавливаются, мобильные share/copy доступны в списке, причина блокировки запуска видна постоянно, название и описание редактируются во время турнира при заблокированных структурных настройках.
- [x] M36: контакты организатора редактируются отдельно и появляются публично только после явного включения; прямое чтение контактных колонок клиентскими ролями закрыто миграцией.

Проверка второго этапа:

- 27/27 целевых браузерных проверок центра матчей: 320/390 px, поиск, фильтры, компактная шапка, double elimination, свайп, один редактор, тап/клавиатура и resize auto-fit.
- 244/244 проверки полной мобильной матрицы: 320/390/430/768 px, RU/EN/LT, owner/editor/counter, tennis/padel/football и все четыре формата.
- 33/33 проверки административных форм и 62/62 общих UI-регрессий, включая native share и публикацию контакта.
- 194/194 логических и SQL-проверок; новая миграция отдельно применена повторно. Production build и `git diff --check` прошли.
- Публичная шапка с длинным описанием измерена в 250 px при viewport 320 и 258 px при 390; страницы не имеют горизонтального переполнения.
- Артефакт: `output/playwright/mobile-foundation/mobile-match-center-320.png` (исключён из Git). Повторяемый сценарий: `tests/manual/mobile-match-center.playwright.js`.
